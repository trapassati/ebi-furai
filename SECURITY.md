# Security

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/trapassati/ebi-furai/security/advisories/new),
not in public issues. You'll get an answer within a few days; fixes are released as soon as they are ready and
credited in the changelog unless you prefer otherwise.

Only the latest release gets security fixes. Docker users get them with `docker compose pull && docker compose up -d`,
service users by running the installer again.
